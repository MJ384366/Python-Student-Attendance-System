PROJECT SUMMARY

Project Title

Student Attendance Manager

1. Introduction

The Student Attendance Manager is a menu-driven console application developed using Python 3. It helps maintain student attendance records and calculate attendance percentages.

2. Problem Statement

Managing student attendance manually can be time-consuming. Calculating attendance percentages and identifying students below the required attendance level can also be difficult. This project provides a simple way to manage these tasks.

3. Objectives

- To add and maintain student records.
- To mark students as Present or Absent.
- To calculate individual attendance percentages.
- To identify students whose attendance is below 75%.
- To save attendance records in a file.

4. Technologies Used

- Programming Language: Python 3
- Editor: Visual Studio Code
- Concepts: Lists, Dictionaries, Functions and File Handling
- Storage File: attendance.txt

5. Main Features

1. Add Student
2. Mark Attendance
3. Show Attendance Percentage
4. Show Attendance Shortage
5. Exit the application

6. Working of the Project

The application displays a menu through which the user can select an operation. Student details are stored using dictionaries inside a list. Attendance is recorded as Present (P) or Absent (A). The program calculates the attendance percentage and identifies students whose attendance is below 75%. Records are saved in a text file so they can be loaded when the application starts again.

7. Expected Outcome

The project provides a simple and organized way to manage student attendance, calculate percentages, and identify attendance shortages.

8. Conclusion

The Student Attendance Manager demonstrates the practical use of Python programming concepts such as lists, dictionaries, functions and file handling. It makes basic attendance management easier and more organized.
