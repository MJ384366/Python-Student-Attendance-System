Student Attendance Manager

Project Description

Student Attendance Manager is a menu-driven Python console application used to manage student attendance records. It allows users to add students, mark daily attendance, calculate attendance percentages, and identify students whose attendance is below 75%.

Features

- Add new students with unique roll numbers.
- Mark attendance as Present (P) or Absent (A).
- Display each student's attendance percentage.
- Identify students with attendance below 75%.
- Store attendance records in a file.
- Load saved records when the program starts.

Technologies Used

- Programming Language: Python 3
- Concepts: Lists, Dictionaries, Functions, File Handling
- Editor: Visual Studio Code

Project Files

- "student_attendance.py" – Main Python program.
- "attendance.txt" – Stores student attendance records.
- "README.md" – Project documentation.

How to Run

1. Open the project folder in Visual Studio Code.
2. Open the Python file.
3. Run the program in the terminal.
4. Follow the menu options displayed on the screen.

Attendance Requirement

The minimum required attendance is 75%.

Project Objectives

- Make attendance management simple and organized.
- Reduce manual attendance calculations.
- Maintain student attendance records using file handling.
- Identify students who need to improve their attendance.

Input Validation

- Prevents duplicate student roll numbers.
- Checks whether the entered roll number exists.
- Accepts only P (Present) or A (Absent) as attendance status.
- Handles students with no recorded classes without division-by-zero errors.
